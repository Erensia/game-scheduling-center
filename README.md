# Game Scheduling Center

# 파밍 관제소

모바일 가챠 게임(명조, 젠존제 등) 캐릭터 육성 상태와 주간 컨텐츠를 관리하는 웹앱입니다.

## 사용 방법

1. 압축을 풀면 나오는 `farming-control-station` 폴더를 원하는 위치에 둡니다.
2. `index.html` 파일을 더블클릭해서 브라우저로 엽니다. (인터넷 연결 없이도 동작하지만, 폰트를 예쁘게 보려면 인터넷 연결 상태를 권장합니다)
3. 이후로는 이 `index.html`을 열 때마다 이전에 입력한 데이터가 그대로 남아 있습니다.

앱을 열면 먼저 **"🏠 오늘 할 일"** 홈 화면이 보이며, 등록된 모든 게임의 미완료 주간 컨텐츠와 육성 필요 캐릭터를 한 화면에서 확인할 수 있습니다. 특정 게임을 자세히 보려면 왼쪽 사이드바에서 게임을 선택하세요.

캐릭터의 체크리스트를 채운 뒤 카드 하단의 **"템플릿으로 저장"** 버튼을 누르면, 같은 게임의 다른 캐릭터를 추가할 때 그 체크리스트 구성을 그대로 불러올 수 있습니다. 템플릿은 게임별로 따로 저장되므로, 게임마다 다른 용어(예: 명조의 "에코", 젠존제의 "디스크")를 그대로 써도 서로 섞이지 않습니다.

## 앱으로 설치하기 (PWA)

이 앱은 PWA(Progressive Web App)로도 만들어져 있어서, 브라우저 북마크 대신 휴대폰 홈 화면이나 PC 바탕화면에 아이콘으로 설치해 다른 앱처럼 바로 열 수 있습니다. 설치 후에는 인터넷이 없어도 마지막으로 열었던 화면이 그대로 열립니다.

**중요**: 오프라인 캐싱과 설치 기능은 브라우저 보안 정책상 `index.html`을 더블클릭해서 여는 방식(`file://`)으로는 동작하지 않습니다. `http://` 또는 `https://` 주소로 접속해야 합니다.

### 방법 1. GitHub Pages로 배포 (권장)
1. GitHub 저장소 → **Settings → Pages**
2. Source를 "Deploy from a branch"로, 브랜치는 `main`, 폴더는 `/ (root)`로 설정 후 저장
3. 잠시 후 `https://Erensia.github.io/game-scheduling-center/` 형태의 주소가 생성됩니다
4. 이 주소로 접속한 뒤, 브라우저 주소창의 설치 아이콘(⊕) 또는 메뉴의 "홈 화면에 추가"를 누르면 앱으로 설치됩니다

### 방법 2. 로컬 서버로 미리 확인
GitHub Pages에 배포하기 전에 먼저 확인해보고 싶다면, 프로젝트 폴더에서 아래 중 하나를 실행한 뒤:
```bash
npx serve .
```
```bash
python3 -m http.server 8000
```
브라우저에서 `http://localhost:8000` (또는 안내된 주소)으로 접속하면 됩니다.

`file://`로 그냥 열어도 앱 자체는 지금까지처럼 정상 동작합니다 — 다만 설치/오프라인 캐싱만 서버 환경에서 활성화됩니다.

## 데이터는 어디에 저장되나요?

이 앱을 연 브라우저의 **로컬 저장소(localStorage)**에 자동으로 저장됩니다.
즉, 페이지를 닫아도, 컴퓨터를 껐다 켜도 같은 브라우저·같은 폴더 경로에서 다시 열면 데이터가 남아 있습니다.

다만 아래의 경우에는 데이터가 사라질 수 있으니 주의하세요.
- 브라우저의 "인터넷 사용 기록 삭제" 등에서 사이트 데이터/쿠키를 지운 경우
- 시크릿(비공개) 모드로 열었던 경우
- `index.html` 파일을 다른 폴더로 옮기거나 다른 브라우저로 여는 경우 (저장 위치가 파일 경로 기준이라 새 위치/브라우저에서는 데이터가 보이지 않습니다)

## 백업하기 (권장)

화면 상단의 **"백업 다운로드"** 버튼을 누르면 현재 데이터를 JSON 파일로 저장할 수 있습니다.
다른 컴퓨터로 옮기거나, 브라우저를 바꾸거나, 만약을 대비하고 싶을 때 이 파일을 받아두세요.

받아둔 백업 파일은 **"백업 불러오기"** 버튼으로 다시 불러올 수 있습니다. (불러오면 현재 데이터를 덮어씁니다)

다운로드한 백업 파일은 프로젝트 폴더 안의 **`BK/`** 폴더에 모아두는 것을 권장합니다.

## 폴더 구성

```
game-scheduling-center/
├── index.html   — 페이지 구조
├── style.css    — 디자인
├── app.js       — 기능 로직 및 데이터 저장
├── manifest.json — PWA 앱 정보 (이름, 아이콘, 색상)
├── sw.js        — 서비스 워커 (오프라인 캐싱)
├── icons/       — PWA 아이콘 이미지
├── README.md    — 이 파일
├── DEVELOPMENT.md — 개발 문서
├── BK/          — 백업 JSON 파일 보관 폴더
│   └── README.md  — 백업 폴더 사용법
├── docs/backend/ — 백엔드 전환 설계 문서 (요구사항, ERD, API 명세 등)
└── backend/     — Spring Boot 백엔드 프로젝트 (진행 중)
```
